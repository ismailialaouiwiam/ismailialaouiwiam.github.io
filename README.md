# Portfolio — Wiam Ismaili Alaoui

Site statique (une seule page) : https://ismailialaouiwiam.github.io

## Contenu du dossier
- `index.html` : la page complète (français / anglais, thème sombre / clair, démos animées).
- `assets/CV_Wiam_Ismaili_Alaoui.pdf` : le CV proposé au téléchargement.
- `assets/screenshots/` : les captures affichées dans les galeries et dans les démos.

## Mettre le site à jour sur GitHub
1. Ouvrir le dépôt `ismailialaouiwiam.github.io`, puis **Add file → Upload files**.
2. Glisser `index.html`, `README.md` et le dossier `assets` (le contenu de ce dossier, pas le dossier lui-même).
3. Cliquer sur **Commit changes**. Le site se met à jour en une à deux minutes.

## Remplacer une capture
Enregistrer la nouvelle image dans `assets/screenshots/` avec exactement le même nom de fichier : elle remplace l'ancienne partout, sans toucher au code.

## Démos
Les trois démos (ZTNA, MPLS L3VPN, Cité Verte) sont des écrans recréés en HTML/CSS. Elles ne contiennent aucune donnée réelle : les données personnelles sont masquées.
